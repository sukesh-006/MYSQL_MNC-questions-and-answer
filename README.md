# MNC MySQL Interview Questions & Answers

Welcome to the **MNC MySQL Interview Questions & Answers** repository! This project is a curated collection of real-world MySQL queries and database problems frequently asked during campus recruitment drives and technical interviews at top Multinational Corporations (MNCs) like **Amazon, Google, Microsoft, TCS, CTS**, and more.

Whether you are a fresher preparing for your first campus placement or an experienced professional brushing up on database concepts, this repository serves as a quick-reference guide to help you crack your SQL technical rounds.

---

## 🚀 Repository Overview

This repository contains problem statements, actual technical interview questions, and their respective optimized MySQL queries.

### 📁 File Structure

*   **`Top 50 MNC Campus Drive MySQL.md`**: A comprehensive compilation of the top 50 SQL interview questions, covering essential concepts from basic joins to advanced window functions.
*   **`Q1.sql` / `Q2.sql` / `Q3.sql`**: Dedicated SQL scripts containing practical solutions to specific high-frequency interview queries.

---

## 💡 Key Topics Covered

The questions in this repository span a wide range of essential SQL topics, including:
*   **Basic & Advanced Filtering:** `WHERE`, `HAVING`, `LIKE`, Regular Expressions.
*   **Aggregations & Grouping:** `GROUP BY`, `COUNT`, `SUM`, `AVG`, `MAX/MIN`.
*   **Joins:** `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `FULL OUTER JOIN`, and `SELF JOIN`.
*   **Subqueries & CTEs:** Nested queries, Correlated subqueries, and Common Table Expressions (CTEs).
*   **Window Functions:** `ROW_NUMBER()`, `RANK()`, `DENSE_RANK()`, `LEAD()`, and `LAG()`.
*   **Data Modification:** `INSERT`, `UPDATE`, `DELETE`.
